# 历史固件（legacy）

这里只放**旧版本**，用于对照排查，不建议烧到板子上做演示。

| 文件 | 版本 | 说明 |
| --- | --- | --- |
| `mpu6050_ai_test_v3.hex` / `.bin` / `.elf` | v3 | 首次发布版本。开机横幅、命令表、`Collector_Init()` 全部依赖 MPU6050 初始化成功；传感器异常时只打印一行 `MPU6050 init FAIL`，之后命令全部失效。没有 HSI 回退、没有 `WHO_AM_I` 校验、告警灯是阻塞的 600 ms。 |

## 为什么保留 v3

- 已经发出去过，有人可能已经烧在板子上，需要能对上版本；
- 排查"老固件为什么没输出"时可以直接对照（见 [`docs/audit-report.md`](../../docs/audit-report.md)）。

**新用户请直接烧上级目录的 `mpu6050_ai_test_v4.1.hex`。**

> 注：v4（`mpu6050_ai_test_v4.*`）已被 v4.1 取代并移除。v4.1 = v4 + HSI 回退时
> 按实际 PCLK1 重算 TIM2 预分频（保证 1 kHz 采样）。历史版本仍可在 git 历史里找到。
